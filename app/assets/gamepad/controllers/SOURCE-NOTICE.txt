# Gamepad Asset Pack by AL2009man

This is a collection of image assets originally created for VSCViewhttps://github.com/Nielk1/VSCView/, now expanded for general uses such as custom controller overlay, modding, etc. This also includes WIP or unfinished assets.

This is the downloaded Version of the pack, for more information; refer to the GitHub Page
